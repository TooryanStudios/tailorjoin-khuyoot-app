📡 ARCHITECTURE

Browser (React)
  ├─ useOrderTracking() → Real-time order status
  ├─ useOrderAssignments() → Real-time tailor notifications
  └─ useOrderSocket() → Low-level Socket.IO

         ↕ WebSocket (< 100ms latency)
         ↕ + Firestore fallback

Node.js API Server (Port 8788)
  ├─ Socket.IO /orders namespace
  ├─ JWT authentication
  ├─ Event handlers (join, leave, status-change, assignment)
  └─ Firestore listener monitoring

         ↓

Google Firestore
  ├─ orders collection (unchanged)
  ├─ notifications collection (optional)
  └─ All writes still go to Firestore
